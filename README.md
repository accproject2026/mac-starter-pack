# Mac 上手包

給剛拿到 Mac 的人。三份教學，看你現在需要哪一種。

**開這裡：** https://accproject2026.github.io/mac-starter-pack/

| | 什麼時候看 |
|---|---|
| Mac 動手玩 | 還沒開始用，想先摸一遍。畫面裡有一台可以真的點的 Mac |
| Mac 新手上手教學 | 剛拿到，想從頭學一遍。12 章，每章都有圖 |
| Windows 換 Mac | 用過 Windows，某個東西找不到。同一件事以前怎麼做、現在怎麼做並排 |

三份都不需要網路，也可以整包下載下來離線看。

內容裡的每個畫面名稱和設定位置，都在 macOS 27 上一項一項對過。
