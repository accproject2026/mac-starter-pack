    01

    先看這張速查表

    你已經會用電腦了，只是換了一台。開機、上網、打字、存檔、印東西，這些邏輯完全沒變。真正要重新學的，其實就是下面這幾條。

    不用從頭學。把「以前那樣做」換成「現在這樣做」就好。

    用生活來想

    這就像從開了十年的手排車換成自排車。路還是那條路、目的地還是那個目的地，方向盤也還在同一邊，你要重新習慣的只有換檔那隻手。前三天會一直去摸不存在的排檔桿，第四天就忘記有這回事了。

    下面兩張表建議先看過一遍，不用背。真的忘記的時候回來翻，翻個三次就記住了。

    每天都會用到的

    這八條佔了日常操作的九成。只記得住一頁的話，就記這一頁。

    你要做的事以前在 Windows現在在 Mac
    複製、貼上、全選 Ctrl 加 C / V / A 把 Ctrl 換成 Command 就好
    按右鍵 滑鼠右鍵 兩根手指在觸控式軌跡板上按一下
    關掉一個程式 按右上角的 X Command 加 Q。左上角的紅色圓點只關視窗
    找一個程式或檔案 按開始功能表打字搜尋 Command 加 空白鍵，打前幾個字
    打開檔案總管 工作列上的資料夾圖示 Dock 最左邊的笑臉圖示，它叫 Finder
    切換中文和英文 Shift 或 Ctrl 加 空白鍵 Control 加 空白鍵，或直接按 Caps Lock
    截圖 PrintScreen 或剪取工具 Shift 加 Command 加 4，圈出範圍
    切換到另一個程式 Alt 加 Tab Command 加 Tab

    偶爾會用到的

    這幾條不常用，但用到的時候如果不知道，會卡很久。

    你要做的事以前在 Windows現在在 Mac
    剪下檔案貼到別處 Ctrl 加 X 再 Ctrl 加 V 複製之後，用 Option 加 Command 加 V 貼上
    刪掉一個檔案 選起來按 Delete Command 加 Delete，丟到垃圾桶
    看檔案的內容和大小 右鍵選「內容」 Command 加 I，叫「取得資訊」
    程式沒反應，強制關掉 Ctrl 加 Alt 加 Delete Option 加 Command 加 esc
    改系統設定 控制台 左上角蘋果選單，選「系統設定」
    安裝一個軟體 下載 exe，一直按「下一步」 從 App Store 下載，或把 App 拖進「應用程式」
    移除一個軟體 控制台的「新增或移除程式」 把那個 App 拖到垃圾桶
    壓縮或解壓縮 裝 WinRAR 或 7-Zip 右鍵選「壓縮」；解壓縮直接點兩下

    最容易踩到的三個坑

    這三件事，幾乎每個從 Windows 換過來的人都會遇到一次。先知道，就不會嚇到。

    關掉視窗，程式還在跑

    按了左上角的紅色圓點，程式沒有真的結束。要按 Command 加 Q。第 05 章會講清楚。

    捲動的方向是相反的

    兩指往下滑，畫面往上跑。這是預設值，可以改回來。第 04 章有改的地方。

    隨身碟存不進去

    從 Windows 帶過來的隨身碟，很可能只讀得到、存不進去。第 09 章有解法。

    這些事情，你以後不用再做了

    很多 Windows 時代養成的習慣，在 Mac 上是多餘的。省下來的時間拿去做別的事。

    不用裝防毒軟體

    系統本身就有防護，也會自動更新。額外裝的清理或防毒軟體，多半只會拖慢電腦，還很難移除乾淨。

    不用做磁碟重組

    現在的 Mac 用的是固態硬碟，系統自己會整理。沒有「磁碟重組」這個功能，也不需要。

    不用定期清理登錄檔

    Mac 沒有「登錄檔」這個東西。網路上叫你買軟體清理的，對 Mac 來說沒有意義。

    不用每年重灌一次

    Mac 不太會因為用久了就變慢。真的覺得怪，先重新開機，多半就好了。

    02

    Ctrl 換成了 Command

    這是整份教學最重要的一章。你在 Windows 上按了十幾年的 Ctrl，在 Mac 上換成了旁邊那顆 Command。搞定這一件事，八成的不習慣就消失了。

    先找到 Command 鍵：它就在空白鍵的左右兩邊，上面印著一朵四葉的花。

    三顆鍵的對應關係

    記住這三行，其他快速鍵你自己就推得出來。

    這顆鍵以前在 Windows現在在 Mac
    主要的那顆 Ctrl，在最左下角 Command，緊貼著空白鍵
    次要的那顆 Alt Option，就在 Command 外面一顆
    名字一樣的那顆 Ctrl 什麼都能做 Control 很少單獨用，主要拿來切輸入法
    最常見的手誤

    想複製卻按成 Control 加 C，結果什麼都沒發生。因為 Mac 的 Control 不是那顆。手指往右邊移一顆，按空白鍵旁邊那顆才對。

    直接換掉 Ctrl 就成立的

    這一組最好記：你原本會的組合鍵，把 Ctrl 換成 Command，動作完全一樣。

    要做的事按什麼
    複製Command 加 C
    貼上Command 加 V
    全選Command 加 A
    儲存Command 加 S
    復原上一步Command 加 Z
    要做的事按什麼
    在頁面裡找字Command 加 F
    列印Command 加 P
    開新視窗Command 加 N
    關掉這個視窗Command 加 W
    切換程式Command 加 Tab

    換掉 Ctrl 不成立的四件事

    這四個沒有一對一的對應，要另外記。剛好也是新手最常卡住的四個。

    1. 剪下檔案：Mac 沒有這個動作 在 Windows 你會對檔案按 Ctrl 加 X。Mac 的 Command 加 X 只能剪文字，對檔案沒有反應。正確做法是先複製，貼的時候改成「搬移」：在原本的位置按 Command 加 C，到目的地按 Option 加 Command 加 V，檔案就搬過去了，原地不會留一份。
    2. 刪除鍵只往左邊刪 Mac 筆電鍵盤上那顆 delete，等於 Windows 的 Backspace，只會刪掉游標左邊的字。要刪右邊的字，按 fn 加 delete。要刪檔案，是 Command 加 delete。
    3. 強制關掉沒反應的程式 Windows 是 Ctrl 加 Alt 加 Delete。Mac 是 Option 加 Command 加 esc，會跳出一個清單，選那個沒反應的程式，按「強制結束」。
    4. 截圖不是按一顆鍵 Mac 沒有 PrintScreen。Shift 加 Command 加 3 是整個螢幕，Shift 加 Command 加 4 是自己圈範圍，Shift 加 Command 加 5 會打開一整排選項，包含錄影。圖預設會直接存到桌面。

    中文和英文怎麼切

    Windows 上你可能按 Shift 或 Ctrl 加 空白鍵。Mac 上有兩個做法，選一個順手的用就好。

    用組合鍵

    按 Control 加 空白鍵，在你裝的輸入法之間切換。

    裝了三種以上輸入法的話，這個鍵是「上一個」，會在最近用的兩種之間來回跳。

    用 Caps Lock（推薦）

    直接按 Caps Lock 就能在中文和英文之間切換，一顆鍵解決，不用按組合。

    要打全大寫的話，把 Caps Lock 按住不放一秒鐘，燈亮起來就是大寫鎖定。

    如果 Caps Lock 沒有反應

    表示這個功能沒開。去 蘋果選單 › 系統設定 › 鍵盤 › 文字輸入 › 輸入方式 › 編輯裡面，把「使用大寫鎖定鍵來切換上次使用的拉丁輸入方式及目前輸入方式」打開。

    忘記快速鍵的時候，看選單列

    Mac 有一個 Windows 沒有的好處：每個功能旁邊都寫著它的快速鍵。不用背，用久了自然會記得。

    打開任何一個程式，看螢幕最上面那排選單。點開「檔案」或「編輯」，右邊那一欄小小的符號就是快速鍵。⌘ 是 Command、⌥ 是 Option、⇧ 是 Shift、⌃ 是 Control。

    用生活來想

    就像餐廳菜單上每道菜旁邊都標了編號。你不需要背編號，點菜的時候看一眼就好，點久了自然記得「三號是牛肉麵」。

    我用的是外接的 Windows 鍵盤，怎麼辦

    可以直接用，位置會自動對應：Windows 鍵當成 Command，Alt 鍵當成 Option。位置不順手的話，去系統設定 › 鍵盤 › 鍵盤快速鍵 › 變更鍵，可以把每顆鍵指定成你要的功能。

    Mac 鍵盤上沒有 Home、End、Page Up 這幾顆

    筆電鍵盤確實沒有，改用 fn 加方向鍵：fn 加左是 Home、fn 加右是 End、fn 加上是 Page Up、fn 加下是 Page Down。

    按了 F1 到 F12，跑出來的是亮度和音量

    Mac 預設把最上面那排當成功能鍵在用。要它們變回 F1 到 F12，按住 fn 再按。想永遠當 F 鍵用，去系統設定 › 鍵盤 › 鍵盤快速鍵 › 功能鍵，打開「使用F1、F2等按鍵作為標準功能鍵」。

    03

    沒有開始功能表的桌面

    第一次看 Mac 的桌面，會覺得少了東西：左下角沒有開始按鈕，下面那排也不太像工作列。其實該有的都有，只是換了位置。

    Windows 的東西集中在左下角，Mac 拆成上下兩條：上面是選單列，下面是 Dock。

    桌面三個區域的對應

    這一區負責以前在 Windows現在在 Mac
    找程式、找檔案 左下角的開始功能表，打字搜尋 Command 加 空白鍵 叫出 Spotlight，打字搜尋
    看所有裝了什麼 開始功能表的程式清單 Dock 上的「App」，或 Finder 側邊欄的「應用程式」
    切換和固定常用程式 下方工作列 下方的 Dock
    音量、Wi-Fi、電池 右下角通知區域 右上角選單列，開關集中在「控制中心」
    這個程式的功能選單 每個視窗自己上面那排 螢幕最上面那排，會跟著你現在用的程式換

    選單列：Mac 最不一樣的一件事

    這一點值得單獨講，因為它跟 Windows 的邏輯真的不同，很多人用了半年才發現。

    Windows 的做法

    每個視窗自己頭上有一排「檔案、編輯、檢視」。開三個視窗，就有三排選單。

    要用哪個程式的功能，就去那個視窗上面找。

    Mac 的做法

    整個螢幕最上面只有一排選單，而且它顯示的是你現在正在用的那個程式。

    點一下另一個視窗，最上面那排的內容就整個換掉了。左邊第二個字就是程式名稱，看那裡就知道現在是誰。

    用生活來想

    像是會議室門口的那塊電子看板。房間只有一塊看板，上面寫的是「現在裡面在開什麼會」。換一組人進去，看板就換內容。你不會期待每張桌子上都各有一塊。

    找不到功能的時候，先看左上角

    很多人抱怨「這個程式沒有設定」，其實是看錯地方。設定不在視窗裡，在最上面那排選單、程式名稱的下拉選單裡，通常叫「設定⋯」。所有程式都一樣。

    Dock 不完全等於工作列

    長得像，但有一個關鍵差別：Dock 上有圖示，不代表那個程式正在執行。

    這件事以前在 Windows現在在 Mac
    怎麼知道程式在跑 工作列上有沒有那個按鈕 看圖示下方有沒有一個小點
    把常用程式放上去 右鍵選「釘選到工作列」 把 App 直接拖到 Dock 上，或右鍵選「保留在Dock上」
    拿掉不要的 右鍵選「取消釘選」 右鍵選「從Dock中移除」，或直接拖出 Dock 往桌面一丟
    右邊那一區 通知區域的小圖示 最近用過的 App、下載項目和垃圾桶

    垃圾桶在 Dock 最右邊，不在桌面上。這也是常找不到的東西之一。

    取代開始功能表的兩個工具

    Windows 找東西只有一個入口，Mac 拆成兩個，各有各的場合。

    1. Spotlight：知道名字就用它 按 Command 加 空白鍵，打前兩三個字，按 Return。程式、檔案、信件、設定選項都找得到，還能直接算數學和換匯率。這是 Mac 上最好用的一招，建議從第一天就開始用。
    2. 「App」：想用眼睛慢慢找就用它 Dock 上有一個由小方格組成的圖示，叫「App」。點下去會蓋滿整個螢幕，列出所有裝好的程式，像手機的主畫面一樣。想不起來名字、只記得圖示長什麼樣的時候用這個。
    3. 四指往上滑：看現在開了哪些視窗 四根手指在觸控式軌跡板上往上滑，所有開著的視窗會攤開來排在螢幕上，這叫「指揮中心」。等於 Windows 的 Alt 加 Tab 攤開版，視窗開很多的時候特別好用。

    幾個「它去哪了」的答案

    「我的電腦」在哪裡

    Mac 沒有這個圖示，因為你平常不需要它。你的檔案在 Finder 側邊欄的「桌面」「文件」「下載項目」裡，直接點就到。真的想看整顆硬碟，在 Finder 選單列點「前往」再選「電腦」。第 06 章會完整說明。

    「顯示桌面」的按鈕在哪

    Windows 是工作列最右邊那一小條。Mac 是用手勢：拇指和另外三根手指張開，所有視窗會退到旁邊，露出桌面。再捏回來就復原。

    怎麼關機、重新開機

    點螢幕左上角的蘋果圖示，裡面有「睡眠」「重新開機」「關機」。不過 Mac 平常不太需要關機，闔上螢幕它就睡了，開蓋馬上能用。

    桌面上為什麼一個圖示都沒有

    Mac 桌面預設是乾淨的，硬碟、網路、資源回收筒都不會放在上面。你自己存到桌面的檔案還是會出現。想讓外接隨身碟顯示在桌面，在 Finder 選單列點「Finder」再選「設定⋯」，在「一般」裡勾「外接磁碟」。

    04

    右鍵在哪、捲動反了

    觸控式軌跡板上看不到左右鍵，滑起來的方向還跟以前相反。這兩件事是換過來的第一天最不舒服的地方，五分鐘就能解決。

    右鍵沒有不見，它變成「用兩根手指按一下」。

    如果你比較習慣「點一下」而不是「按下去」，可以改成兩指輕點就好，不用真的壓下去。設定的地方在下面。

    右鍵的三種按法，挑一種

    你的裝置以前在 Windows現在在 Mac
    筆電的觸控板 板子右下角，或右鍵按鈕 兩根手指按一下（預設）
    Apple 的妙控滑鼠 滑鼠右鍵 滑鼠表面偏右的位置按一下
    任何一般滑鼠 滑鼠右鍵 一樣按右鍵，可以直接用
    不想用兩指的話 不適用 按住 Control 再點一下，效果一樣
    妙控滑鼠第一次用要注意

    它整片表面都是按鈕，看不出左右。預設是有分左右的，按偏右邊就是右鍵。如果按了沒反應，去系統設定 › 滑鼠，確認「輔助按鈕」是設成「按一下右側」。

    捲動方向：先決定要不要改

    這是最多人第一天就想罵人的設定。花一分鐘決定，決定好就別再動它。

    維持預設（自然捲動）

    和 iPhone、iPad 的方向一致。如果你手機用得多，兩三天就會習慣，而且以後在手機和電腦之間切換不會錯亂。

    建議先撐三天再決定。

    改回 Windows 的方向

    去系統設定 › 觸控式軌跡板 › 捲動與縮放，把「自然捲動」關掉。

    用滑鼠的話，系統設定 › 滑鼠裡面也有一個一樣的開關，兩邊是分開的，都要關。

    四個值得學的手勢

    Windows 的觸控板手勢多半可有可無，Mac 上這四個是真的每天都會用到。

    1. 兩指上下滑：捲動頁面 取代滑鼠滾輪。左右滑則是回上一頁、下一頁，在瀏覽器裡特別好用，比找返回按鈕快。
    2. 兩指捏合或張開：縮放 和手機一樣。看照片、看 PDF、放大網頁字體都用它，不用再按 Ctrl 加滾輪。
    3. 四指往上滑：看所有開著的視窗 這是「指揮中心」。視窗開太多找不到的時候滑一下，全部攤開讓你挑。等於 Windows 的工作檢視。
    4. 四指左右滑：切換全螢幕的程式 把程式切成全螢幕之後，它會變成一個獨立的桌面。四指左右滑就在這些桌面之間移動，等於 Windows 的虛擬桌面切換。

    全部的手勢清單在系統設定 › 觸控式軌跡板，每一項旁邊都有動畫示範，看得到才學得起來。

    覺得游標太慢或太快

    這也是換機第一天常有的感覺，因為兩邊出廠的預設速度不一樣。

    調游標速度

    系統設定 › 觸控式軌跡板 › 點按，最上面那條「軌跡速度」。滑鼠的話在「滑鼠」裡，一樣的位置。

    改成輕點就好，不用壓

    同一頁裡把「點一下來選按」打開。之後手指輕碰就等於按一下，用久了手比較不累。

    可以用外接的 Windows 滑鼠嗎

    可以，插上去就能用，左右鍵和滾輪都正常。有些滑鼠的側邊按鍵要裝廠商的驅動程式才會動，那個要去該廠牌的網站下載 Mac 版。

    滑鼠滾輪的方向也是反的嗎

    是。滑鼠和觸控式軌跡板的自然捲動是兩個獨立的開關，改了觸控板不會連動到滑鼠，要在系統設定 › 滑鼠裡另外關一次。

    兩指按了跳出選單，但選項比 Windows 少很多

    正常。Mac 的右鍵選單刻意保持精簡。按住 Option 再按右鍵，選單會多出一批進階選項，例如「拷貝為路徑名稱」。

    05

    紅色叉叉不是關程式

    視窗右上角的三顆按鈕跑到左上角，還變成了三個小圓點。位置換了不打緊，重點是紅色那顆的意思跟 Windows 不一樣。

    紅色只關掉這個視窗，程式還在背景跑。要真的結束，按 Command 加 Q。

    三顆圓點各是什麼

    這顆按鈕以前在 Windows現在在 Mac
    紅色（最左邊） 右上角的 X，按了程式就關了 只關掉這個視窗，程式繼續在背景執行
    黃色（中間） 最小化，縮到工作列 縮到最小，縮進 Dock 的右邊那一區
    綠色（最右邊） 最大化，填滿桌面但工作列還在 進入全螢幕，連上面那排選單列都會藏起來
    綠色不是「最大化」

    很多人按了綠色之後嚇一跳，因為整個畫面被吃掉，上面那排選單也不見了。要退出來，把滑鼠移到螢幕最上緣，選單列會滑下來，再點一次綠色圓點；或直接按 esc。

    想要 Windows 那種「最大化」的話

    Mac 上有兩個做法可以達到差不多的效果，不用被綠色全螢幕綁住。

    最快：按住 Option 再點綠色

    按住 Option 不放，綠色圓點裡的符號會變成加號，這時候點下去就是「填滿桌面但選單列還在」，最接近 Windows 的最大化。

    要並排兩個視窗

    把視窗拖到螢幕左邊或右邊的邊緣，放手就會自動貼齊一半，和 Windows 一樣。

    也可以在選單列的「視窗」選單裡找「移動與調整大小」，裡面有「填滿」「左側」「右側」可以選。

    怎麼確認程式真的關了

    這件事影響的不只是強迫症，程式一直開著會吃電池。

    1. 看 Dock 圖示下面有沒有小點 有小點就是還在跑。沒有小點，才是真的關掉了。這是最直接的判斷方式，養成掃一眼的習慣。
    2. 用 Command 加 Q 結束 在那個程式的視窗上按 Command 加 Q，或在選單列點程式名稱、選「結束」。這才等於 Windows 按右上角 X 的效果。
    3. 程式沒反應就強制結束 按 Option 加 Command 加 esc，跳出來的清單選那個卡住的程式，按「強制結束」。這等於 Windows 的工作管理員。
    4. 想看誰在吃資源，用「活動監視器」 按 Command 加 空白鍵，打「活動監視器」。它就是 Mac 版的工作管理員，可以看 CPU、記憶體、電池用量，也能在這裡結束程式。

    視窗之間怎麼切

    Windows 的 Alt 加 Tab 是切「視窗」，Mac 的 Command 加 Tab 是切「程式」。這個差別會讓人找不到自己剛剛開的那個檔案。

    你想做的按什麼
    換到另一個程式Command 加 Tab
    同一個程式的不同視窗之間換Command 加 `（Tab 上面那顆）
    攤開現在所有視窗來挑四指往上滑
    只看這個程式開了哪些視窗Control 加 下方向鍵
    用生活來想

    Windows 像是把所有文件都攤在同一張桌上，Alt 加 Tab 是一張一張翻。Mac 是先分成好幾個抽屜，Command 加 Tab 換抽屜，換到抽屜之後再挑裡面的文件。

    黃色圓點縮起來的視窗，怎麼叫回來

    它會縮到 Dock 最右邊、垃圾桶左邊那一區，變成一個小縮圖，點一下就回來。找不到的話，用 Command 加 Tab 切到那個程式也會回來。

    關掉所有視窗之後，程式還開著會怎樣

    不會怎樣，它只是待命，占用的資源很少。不過選單列會一直是那個程式的，容易看錯。介意的話就順手 Command 加 Q。

    為什麼有些程式關掉視窗就真的結束了

    因為那類程式只有一個視窗，關掉就沒事做了，例如「系統設定」「計算機」。有文件概念的程式（瀏覽器、文書、郵件）才會留在背景。

    06

    沒有 C 槽，檔案在哪

    打開 Finder 卻找不到 C 槽 D 槽，是每個從 Windows 換過來的人的第一個問號。答案是：Mac 也有硬碟，只是它不希望你花時間在那裡面。

    忘掉磁碟機代號。你的東西只在五個資料夾裡：桌面、文件、下載項目、圖片、影片。

    Finder 就是檔案總管

    Dock 最左邊那個藍色笑臉。它永遠關不掉，因為它就是桌面本身。

    Finder 各部位對應檔案總管的哪一塊

    這個部分以前在檔案總管現在在 Finder
    左邊那一排捷徑 快速存取 側邊欄，可以把常用資料夾拖進去
    顯示方式 大圖示、詳細資料、清單 圖像、列表、直欄、圖庫共四種
    看得到目前路徑 上方位址列，一直都在 路徑列，預設關著，按 Option 加 Command 加 P 打開
    直接打路徑跳過去 在位址列打 C:\... Shift 加 Command 加 G，叫「前往檔案夾」
    搜尋 右上角搜尋框 右上角搜尋框，或 Command 加 F

    兩個一定要先打開的設定

    這兩個預設是關的，而 Windows 使用者非常依賴它們。開了之後 Finder 會順手很多。

    1. 顯示副檔名 Mac 預設把 .docx .jpg 這些藏起來。在 Finder 選單列點「Finder」選「設定⋯」，切到「進階」，勾「顯示所有檔案副檔名」。
    2. 顯示路徑列 打開 Finder，按 Option 加 Command 加 P。視窗底部會多一條，顯示你現在在哪一層，跟位址列一樣好用。
    3. 順便：顯示捲軸 Mac 的捲軸平常是隱藏的，很容易誤以為「這個資料夾就這幾個檔案」。去系統設定 › 外觀 › 顯示捲軸，改成「總是」。

    檔案操作對照

    你要做的事以前在 Windows現在在 Mac
    新增資料夾 Ctrl 加 Shift 加 N Shift 加 Command 加 N
    重新命名 按 F2 選起來按 Return，或點一下名字停一下再點
    看檔案資訊 右鍵「內容」 Command 加 I，叫「取得資訊」
    不開軟體快速看內容 沒有這個功能 選起來按空白鍵，叫「快速查看」，非常好用
    刪除 按 Delete Command 加 Delete
    清空資源回收筒 桌面右鍵「清空資源回收筒」 Dock 最右邊的垃圾桶，右鍵「清空垃圾桶」
    複製一份在原地 複製再貼上 Command 加 D，叫「複製」
    壓縮成一包 右鍵「傳送到」再選壓縮資料夾 右鍵選「壓縮」，直接產生 zip
    再說一次剪下貼上

    這是 Finder 裡最容易卡住的一件事。Command 加 X 對檔案沒有作用。要搬移檔案：先在原地 Command 加 C 複製，到目的地按 Option 加 Command 加 V。或者更簡單：開兩個 Finder 視窗，直接把檔案拖過去。

    檔案存到哪去了

    從瀏覽器下載的東西，一律進「下載項目」。這一點和 Windows 一樣，路徑不同而已。

    從程式裡按「儲存」的話，Mac 的儲存視窗預設是收起來的小視窗，只顯示檔名和一個位置下拉選單。很多人沒注意到那個位置，按了儲存就找不到檔案。點右邊的小箭頭可以展開成完整的資料夾清單，就跟 Windows 的另存新檔一樣。

    找不到剛存的檔案

    按 Command 加 空白鍵 打檔名。或打開 Finder 側邊欄的「最近項目」，剛動過的檔案都在那裡。

    想固定存到某個資料夾

    把那個資料夾拖進 Finder 側邊欄，之後儲存視窗的位置清單裡就會有它，一點就到。

    那我的硬碟到底在哪

    它叫「Macintosh HD」。在 Finder 選單列點「前往」再選「電腦」就看得到。裡面的「系統」「資源庫」這些資料夾請不要動，那是系統的東西，也刪不掉。

    可以再分一個 D 槽出來放資料嗎

    技術上可以，但不建議。Mac 的設計是一顆硬碟一個空間，分割之後兩邊都會卡，反而更難用。要分開放，用資料夾就好，或外接一顆硬碟。

    資料夾裡的檔案好像不齊，只有幾個

    先兩指往上滑看看下面。Mac 的捲軸平常隱藏，右邊沒有灰色長條不代表沒有東西。上面第三個設定就是在講這件事。

    Finder 搜尋出來的東西太多、都不是我要的

    搜尋框下面有一列可以選「這部 Mac」或「目前的檔案夾」，改成目前的檔案夾就會準很多。想固定這個行為，在 Finder 設定的「進階」裡把搜尋改成「搜尋目前的檔案夾」。

    07

    沒有 exe，怎麼裝軟體

    Windows 裝軟體是「下載一個檔案，一直按下一步」。Mac 的邏輯不一樣：多數時候你只是把一個東西拖進資料夾，就算裝好了。

    Mac 上的 App 是一個完整的東西，不是一堆散裝檔案。搬進去叫安裝，丟掉就叫移除。

    用生活來想

    Windows 裝軟體像請師傅來家裡裝冷氣：要打洞、拉管線、接電，東西散在牆裡牆外，拆的時候也得請人來拆。Mac 比較像買一台電風扇，從箱子裡拿出來放到客廳就能用，不要了就整台搬走，牆上不會留洞。

    三種安裝來源

    來源以前在 Windows現在在 Mac
    官方商店 Microsoft Store，很少人用 App Store，最安全，更新會自動處理
    從官網下載 下載 .exe 或 .msi，一路按下一步 下載 .dmg，打開後把 App 拖進「應用程式」
    需要安裝程式的 同上 少數會給 .pkg，那個就跟 Windows 一樣按下一步

    日常用的軟體九成以上走前兩種。看到 .dmg 不要怕，它不是壓縮檔，是一個「虛擬光碟」。

    dmg 的正確安裝流程

    這是新手最常做錯的一件事，錯了不會壞掉，但每次開軟體都會怪怪的。

    1. 在「下載項目」裡點兩下那個 dmg 會跳出一個視窗，同時 Finder 側邊欄下方會多出一個像磁碟的東西。這代表它被「掛載」起來了，像插了一張光碟進去。
    2. 把 App 圖示拖到「應用程式」資料夾 視窗裡通常已經幫你放好了「應用程式」的捷徑，直接拖過去放手，複製完成就是安裝完成。這一步就是全部的安裝過程。
    3. 退出那個磁碟，再把 dmg 刪掉 在 Finder 側邊欄找到剛才多出來的那一項，點旁邊的退出符號。然後把「下載項目」裡的 dmg 丟到垃圾桶，它已經沒用了。
    4. 之後從「應用程式」或 Spotlight 打開 按 Command 加 空白鍵 打前幾個字就能開。想放到 Dock，開起來之後在 Dock 圖示上按右鍵，選「保留在Dock上」。
    最常見的錯誤：直接從 dmg 裡開來用

    沒有拖進「應用程式」就直接點兩下開，軟體是會動，但那等於「每次都要先插光碟」。徵狀是：重開機之後找不到那個 App、或桌面上一直有一個磁碟圖示賴著不走。發現弄錯了不用重下載，把 dmg 再打開一次，補拖進去就好。

    第一次打開被系統擋下來

    從官網下載的軟體，第一次開可能會跳出「已阻擋⋯以保護你的Mac」。這不是中毒，是系統的預設保護。

    如果你信任這個來源

    去系統設定 › 隱私權與安全性，往下捲到「安全性」那一段，會看到剛才被擋的那個 App，旁邊有一顆「強制打開」，點下去就好。

    只要做一次，以後直接開。

    如果你不確定來源

    那就不要開。這個提示本身就是在提醒你：這個軟體不是從 App Store 來的，系統也認不出開發者。

    先回頭確認一下，你是不是從搜尋結果的廣告連結、而不是官方網站下載的。

    同一頁的「允許以下來源的應用程式」建議維持「App Store與已知的開發者」，不要改成「任何來源」。

    怎麼移除軟體

    沒有「新增或移除程式」這個地方，因為不需要。

    1. 從「應用程式」拖到垃圾桶 打開 Finder，點側邊欄的「應用程式」，找到那個 App，拖到 Dock 最右邊的垃圾桶。清空垃圾桶就真的沒了。
    2. 或在「App」畫面上長按 從 App Store 裝的軟體，可以在 Dock 的「App」裡，按住那個圖示不放，圖示旁邊出現刪除記號就能移除。
    3. 有些軟體自帶移除工具 Adobe、部分防毒和驅動程式類的軟體例外，它們在「應用程式」裡會有一個 Uninstaller，用那個移除比較乾淨。
    Windows 上買的軟體，可以裝到 Mac 嗎

    程式本身不能直接用，兩邊是不同的系統。不過很多軟體有 Mac 版，而且授權常常是共用的（例如 Microsoft 365、Adobe），去官網用同一個帳號登入下載 Mac 版就好。純 Windows 專用的軟體則要找替代品，下一章有對照表。

    要不要裝防毒軟體

    一般使用不用。macOS 內建的防護會自動更新，而且第三方的清理和防毒軟體在 Mac 上經常是反效果：吃資源、跳廣告、還很難移除。公司規定要裝的話另當別論。

    移除 App 之後，設定檔會留著嗎

    會留一點點在系統的資源庫裡，但通常只有幾 KB，不影響效能也不占空間，可以不用理它。好處是之後重新安裝，設定還在。

    公司要用的系統只支援 Windows，怎麼辦

    先確認是不是網頁版的，如果是，用 Safari 或 Chrome 開通常沒問題。真的是 Windows 專用軟體，可以問公司有沒有遠端桌面可以連，那是最簡單的解法。

    注音輸入法用起來不太一樣

    常見原因是 Windows 常用的標楷體、新細明體 Mac 沒有。要跟同事來回改稿的話，兩邊都改用共通的字體（例如微軟正黑體或思源黑體），或最後定稿轉 PDF 再寄。

    隨身碟、印表機、螢幕

    周邊設備多半插上去就能用，不用找驅動程式光碟，也不用去官網下載。只有一件事會卡住人，而且卡得很莫名其妙：隨身碟存不進去。

    從 Windows 帶來的隨身碟，Mac 讀得到，但常常存不進去。這不是壞了。

    用生活來想

    這就像一本用你看得懂的語言寫的筆記本，你讀得很順，但那本子的裝訂方式讓你沒辦法往裡面加頁。內容沒問題，是本子的規格不合。

    為什麼存不進去

    因為那顆隨身碟是 NTFS 格式，那是 Windows 專用的格式。macOS 可以讀，但不能寫。要兩邊都能存，格式要換成 exFAT。

    格式在 Windows在 Mac
    NTFS 讀寫都行，Windows 的預設 只能讀，不能存
    exFAT 讀寫都行 讀寫都行，兩邊互通就用這個
    FAT32 讀寫都行 讀寫都行，但單一檔案不能超過 4GB
    APFS 看不到這顆碟 讀寫都行，Mac 專用
    怎麼知道自己的是哪一種

    把隨身碟插上，在 Finder 側邊欄點一下它，按 Command 加 I，「格式」那一欄就會寫。看到 Windows NT 檔案系統就是 NTFS。

    要改格式的話

    改格式會清空整顆碟。裡面的東西先複製到 Mac 上（讀是讀得到的），再動手。

    1. 先把裡面的檔案全部複製出來 插上隨身碟，把內容整包拖到 Mac 的「文件」或桌面。這一步不做，等一下全部會不見。
    2. 打開「磁碟工具程式」 按 Command 加 空白鍵，打「磁碟工具程式」。左邊清單裡點選那顆隨身碟，注意是點裝置本身，不是它底下那一層。
    3. 按上方的「清除」，格式選 ExFAT 名稱隨便取，格式選 ExFAT，架構如果有得選就選「主開機記錄」。按「清除」，幾秒就好。
    4. 把檔案複製回去 現在這顆碟在 Mac 和 Windows 兩邊都能讀寫了。把剛才備份出來的東西丟回去。

    不想改格式、又非得在 Mac 上寫入 NTFS 的話，市面上有付費的第三方驅動程式。一般用途不建議，換成 exFAT 單純很多。

    拔隨身碟之前要先退出

    以前在 Windows

    右下角的「安全地移除硬體」，很多人其實直接拔。

    現在在 Mac

    在 Finder 側邊欄，那顆碟的名字旁邊有一個退出符號，點一下。名字消失了才拔。

    也可以把它從桌面拖到垃圾桶，垃圾桶會變成退出符號，這是 Mac 的老習慣。

    沒退出就直接拔，通常沒事，但檔案正在寫入的時候拔會壞檔。養成習慣比較保險。

    印表機、螢幕、其他周邊

    設備以前在 Windows現在在 Mac
    印表機 裝驅動程式，再新增印表機 同一個 Wi-Fi 下多半自動出現，列印時直接選
    找不到印表機 控制台的裝置和印表機 系統設定 › 印表機與掃描器，按加號
    外接螢幕 接上去，按 Win 加 P 選模式 接上去自動延伸；系統設定 › 顯示器可改成鏡像
    藍牙耳機、鍵盤 設定裡新增藍牙裝置 右上角控制中心的藍牙，或系統設定 › 藍牙
    接投影機 HDMI 線，按 Win 加 P HDMI 或 USB-C 轉接，接上就投；要同畫面就開鏡像
    SD 卡、讀卡機 插上出現一個磁碟機 插上出現在 Finder 側邊欄，用完一樣要退出
    要去哪裡下載印表機驅動程式

    通常不用。macOS 內建了大部分廠牌的驅動，插上或在同一個 Wi-Fi 下就會自己抓。真的抓不到，才去該廠牌官網找 macOS 版本。掃描功能有時候要裝廠商的軟體才完整。

    MacBook 的孔好像不夠用

    比較新的機型主要是 USB-C 埠。要接舊的 USB 隨身碟、HDMI、SD 卡，買一個多功能轉接器就解決了，這是最常見的第一個配件。

    外接螢幕的字看起來很模糊

    去系統設定 › 顯示器，那台螢幕的解析度選「預設」那一格。非 Apple 的螢幕在某些解析度下會糊，換一格通常就清楚了。

    頭三天照著做就好

    前面九章不用一次看完。這一章把該做的事排成三天，每天十分鐘，做完你就上手了。

    不用一次學會全部。真正影響體驗的只有幾個設定，先把它們調好。

    第一天：把手感調對

    今天的目標是「用起來不彆扭」，全部在系統設定裡，十分鐘搞定。

    1. 決定捲動方向 系統設定 › 觸控式軌跡板 › 捲動與縮放。要維持 Mac 的方式就不動，想跟 Windows 一樣就把「自然捲動」關掉。用滑鼠的話，「滑鼠」那一頁也要關一次。
    2. 打開「點一下來選按」 同樣在觸控式軌跡板的「點按」那一頁。打開之後手指輕碰就等於按一下，不用整片壓下去，一天下來手會輕鬆很多。
    3. 打開副檔名和捲軸 Finder 選單列點「Finder」選「設定⋯」，在「進階」勾「顯示所有檔案副檔名」。再去系統設定 › 外觀 › 顯示捲軸改成「總是」。這兩個是 Windows 使用者最依賴的視覺線索。
    4. 練一次 Command 加空白鍵 按一次，打「計算機」，按 Return。這一招你之後每天會用幾十次，今天先讓手記住。

    第二天：把東西放進來

    今天處理資料和軟體。舊電腦先不要清空，確認都搬好了再說。

    1. 登入 Apple 帳號 用你 iPhone 上那一組。登入之後備忘錄、行事曆、照片、密碼會和手機同一份。不確定密碼就先拿手機確認，不要臨時新辦一組。
    2. 把舊電腦的檔案搬過來 最單純的做法：用一顆 exFAT 格式的隨身碟或外接硬碟分幾趟搬。檔案不多的話，用雲端硬碟或寄給自己也行。
    3. 裝三到五個你每天用的軟體 先只裝真的每天開的那幾個，例如瀏覽器、通訊軟體、辦公室文書。其他的等到真的要用再裝，別一口氣把舊電腦上的東西全搬過來。
    4. 整理 Dock 用不到的圖示右鍵選「從Dock中移除」，常用的開起來之後右鍵選「保留在Dock上」。整理過的 Dock 用起來差很多。

    第三天：設好備份就結束

    這一天只有一件事，但它比前面所有事情加起來都重要。

    1. 買一顆外接硬碟，設定「時光機」 接上外接硬碟，系統會問你要不要拿來備份，按確定。之後它會自己每小時備份一次，你完全不用管。這是 Mac 上最省事、也最救命的功能。
    2. 確認 iCloud 有在同步 系統設定 › iCloud，看照片、備忘錄這些有沒有打開。這是雲端同步，和時光機的完整備份是兩件事，兩個都要有。
    3. 舊電腦先留著一個月 確定所有東西都在新電腦上、也備份過一輪之後，再處理舊機。急著清空是最容易後悔的一步。

    三天之後，遇到問題怎麼辦

    先重新開機

    聽起來像廢話，但 Mac 平常很少關機，開了幾週之後偶爾會怪怪的。重開一次解決一大半。

    問內建的「使用說明」

    選單列最右邊的「輔助說明」，打關鍵字就找得到官方步驟，而且是繁體中文的。

    用 Spotlight 找設定

    想不起來某個設定在哪一頁，按 Command 加 空白鍵 直接打設定名稱，會直接跳到那一頁。

    回門市問

    買機的門市可以協助設定和操作教學。帶著電腦來，當場示範一次比看十頁說明快。

    最後一句

    換系統會不習慣是正常的，通常一到兩週就過去了。真的想不起來某個操作的時候，回到第 01 章那兩張速查表看一眼就好，不用從頭讀。
